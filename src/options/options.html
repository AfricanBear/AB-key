This JSON is what Save stores, toggles above included: switching a toggle edits its flag here, and Import shows the file's flags on the toggles. Hotkeys are written like alt+g or alt+shift+1 (modifiers ctrl, alt, shift, meta, then the key); letters match the physical key, so any keyboard layout works. Save warns about hotkeys that cannot fire.
