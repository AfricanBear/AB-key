A+B key

Configure command bindings and action profiles

Features

Hover a column header in a dataset Viewer and click the pin to keep the column on the left while scrolling. Pinned columns and column widths are remembered per dataset in this browser only.

Configuration

Alt+1–5 click the right toolbar rail buttons by position, top to bottom; the rail differs by object type. Open the A+B key panel on an Abacum page to see what each hotkey does there.
